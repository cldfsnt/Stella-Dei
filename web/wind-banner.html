Wind preview · instructions ▾

Play starts a fresh wind-dispersal Origin world. Tools → World shows the active law and lets you explicitly restart. Loading a classic save keeps its old law.

In that world, Tools → Plant → Seed Pioneer uses real resources for a founder with 50% inherited aerial allocation. For many patches, review Plan Pioneer Auto-seed before applying; adding colonies may slow play. Ordinary founders start with zero aerial allocation; descendants may vary. Wind can carry later offspring farther; arrivals and establishment can fail.

Preview saves are separate from the main game and Wetlands. Load restores only this preview’s saved world; a classic world stays classic. No automatic migration or seed bank.
