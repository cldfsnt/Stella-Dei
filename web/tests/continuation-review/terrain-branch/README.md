# Terrain fragment branch experiment: HOLD

One isolated fragment-shader control-flow change, no production source edit: the original clearSurface branch calculates a first land/water/relief color that mapContext later overwrites. Move those calculations into the mapContext=false else branch; shared wet/ice and contextual arithmetic order stay unchanged. No quality setting, geometry simplification or hidden UI. Both original and candidate shaders are included. Same native executable selects embedded candidate only when STELLA_TERRAIN_BRANCH is set.

## Acceptance

- 24 processes exit0, three alternating pairs for early and natural30day worlds at390×700 and1366×768.
- Each process measures paused,6h/sec target,24h/sec target after12 warmup frames,60 measured frames each, actual update/render/gl.finish/swap. Fixed input delta is workload control, not actual browser achieved speed.
- All36 per-pace complete saved-state pairs byte-identical. All20 screenshot pairs (5 actual display modes ×2 worlds ×2 resolutions) byte-identical. Rendering-only screenshot traversal asserts before/after complete save identity.
- Native EGL llvmpipe, browser rendering policy, not Android/browser/laptop hardware. No standalone WebGL shader gate or noncontext screenshot proof; candidate is not recommended for release.
- Actual1366 normal rendered screenshot inspected: terrain, colony forms, amber markers and UI present, not empty images. review.png retained. Existing native allocator shutdown warnings preserved.

## Reproduce / limits

Start from current-v52 copied CPU replay baseline generated by egl-cpu-resolution-prepare.py then egl-cpu-coefficient-replay-prepare.py, as recorded by latitude-cache research. Run egl-terrain-branch-prepare.py BASE OUTPUT. Build OUTPUT/main.zig with egl-terrain-branch-build.zig, `-Dsource` and `-Dshim` absolute paths, Zig0.13 ReleaseSafe. This fixture changes copied policy gates only, not actual production shaders or engine. run.py expects `build/bin/stella-egl` and sibling cpu-v44 actual QA save inputs. Logs/source/output hashes pin tested inputs.

Two initial fixture builds failed: addCSourceFiles disallowed an absolute shim path, then image `path` shadowed outer save path. Corrected build helper uses addCSourceFile.cwd_relative and screenshot variable image_path. Failed logs retained; final build passed. No production fix is implied. Current source contains native proof helpers beyond original v52 labels; full copied source hashes are authoritative.
