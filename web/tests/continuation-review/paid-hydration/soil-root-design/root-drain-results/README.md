## Mechanic implications

The candidate demonstrates a real limited root-water response and paid inheritance under the actual scheduler, without forcing victory. Raising conductance cannot address this example: even1 already supplies full brief demand, and the pool quickly overtops the canopy. Repeated god-water removal or height changes would create a different experiment, not rescue this result. First repair/attribute water material loss without outcome-tuned biology. Then establish whether the unchanged world supplies persistent exposed, moist substrate for autonomous propagules, and only subsequently test from-zero inherited root variation. Neither a new trait label nor continuous irrigation should substitute for that missing habitat/selection proof.
