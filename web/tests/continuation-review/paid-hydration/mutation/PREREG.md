Tuple44bytes, no pointer/time/habitat/fitness/legacy-RNG-draw input. Event when digestbyte0 low6bitszero (modeled1/64); sign digestbyte1 lowbit (modeledhalf each); signed step exactly1/32. Clamp allocation[0,1]. Most births unchanged. Atzero negative proposals clamp unchanged, positive proposals start1/32 (modeled1/128 expressed); analogous upperbound. Signed proposals unbiased in interior, NOT unbiased realized drift atbounds. No reflected/favorable reroll and no phenotype-dependent event chance. Other sixtrait draws untouched.

This is domain-separated deterministic pseudorandomness, not a proof of mathematical/random independence; finite hash outputs can correlate/collide. Child IDs are global birthserials, so a different birthhistory can change later identities/keys. No claim schedule-independent lineage trajectory. No persistent stream cursor is needed: worldseed and lineage/generation IDs are already saved.
