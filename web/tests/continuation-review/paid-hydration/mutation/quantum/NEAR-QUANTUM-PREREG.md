# Near-quantum numerical transaction: preregistered proposal

Status: design only, awaiting independent review. No production change, no experimental implementation or new biological trial. The prior six-arm outcomes remain frozen. Private raw evidence backup is complete per coordinator.

## Fixed scope

Keep existing conservative take() behavior whenever it yields a positive represented debit. Only if positive simultaneous capacity deficit yields zero debit, consider exactly one downward representable f32 source step. Refuse zero source, zero demand, nonfinite conversion/debit, invalid receiver state, or overflow. No direct consumption of liquid_return, no extra tissue, mutation change, or favorable habitat selection.

The proposed threshold is numerical, not biological: actual source quantum must be no greater than twice total requested deficit. Budget for same-call receiver grants is min(actual debit,total deficit). Fair proportional grants use the existing ordered sums and downward receipt protections. Compute receivers on a bounded local copy before committing. Stronger proposed acceptance: actual represented source debit minus actual represented receiver credits must be <= actual receiver credits; reject the fallback unchanged otherwise. This guarantees withheld remainder no greater than actually granted, even near rounding boundaries. Check sums in wider precision in tests, and distinguish finite-precision tolerance from exact arithmetic claims.

All unused water is strictly nonhydrating liquid_return, deposited through the existing physical return path before/after exchange. It is never treated as an uptake source. Existing escrow balance must remain finite and valid; refusal cannot lose water or mutate receivers/source. This does not solve arbitrarily subquantum deficits. It intentionally rejects deep-pool draws that would withhold much more than organisms can receive.
