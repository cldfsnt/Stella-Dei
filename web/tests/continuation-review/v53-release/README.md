# v53 release gate: represented resource accounting

Promotes only the tested arithmetic body and helpers from the frozen realized-receipt candidate (SHA256 9efae4e34a4588413fe59bd2395a19fdcc795a994980bea89e451f5b917898e3), with the experimental pace multiplier removed. No new trait, physiological coefficient, save field, compensator, resource top-up or UI change. Growth receipts use represented tissue gain; upkeep/death receipts use bounded represented removal; photosynthetic-growth support and offspring credit cannot round upward beyond their supplied growth budgets. Grazing, movement and reproduction transactions are otherwise unchanged. Retained roundoff is not fabricated credit.

## Scope and proof

- All 34 production microbial tests pass, including two permanent receiver/removal regressions. Existing transport/session suite passes 56 tests, including imported regressions. These counts overlap, not 90 independent tests.
- Browser-controller suite: 35 tests across 16 files pass. An initial wrong discovery glob found zero tests; its log is retained and is NOT validation. Correct explicit web/tests glob executed the suite.
- Prior frozen candidate: 96 experimental shared-resource runs under unchanged bounds; native and actual wasm32-emscripten ReleaseSafe + emcc-O2 receiver/capacity/48-day regressions agree. Experimental maintenance/pace is NOT shipped.
- Actual coupled engine: eight baseline/candidate arms from natural day30/day60 saves at 1440/720-second steps, each ten simulated days. Exact capture/load and two equally restored continuations pass, with original state restored. This is restored-repeatability, NOT proof uninterrupted and reloaded trajectories are identical.
- Identical-input shadows reduce accumulated absolute C rounding residuals 12–25% and N residuals 2–32% in tested worlds. Per-step maxima and signed whole-world endpoint residuals are mixed; no uniformly better worst-case or global exact-closure claim.
- Clean actual coupled profiling found no reproducible meaningful slowdown. Results and noisy repeat retained in receipt-clean. NOT a speed improvement, FPS/device claim, or a reason to rewrite the language.

## Explicit remaining limits

Tiny real tissue gains can still round the f32 free-nutrient debit to zero; this known witness reproduces natively and in WASM. Aggregate f32 gas receipts and nutrient/detritus stores retain quantization. No arbitrary-duration exact chemistry or elimination of existing hydrology drift is claimed. Existing saves retain their represented state and format; future evolution can differ after a numerical update. The native harness retains inherited allocator teardown warnings. Actual Android/laptop/live-browser graphics execution is not verified; cloud WindowCreationFailed remains a limitation.

The other experiments in this checkpoint are research only: latitude caching and terrain branch changes were withheld for inconsistent timing; a new inherited metabolic-pace trait was withheld because scarcity benefit did not establish lasting invasion after recovery. Real grazing and fire playtests demonstrate existing mechanics, not new fire adaptation or animals.

Archived experimental harnesses must be replayed against their pinned pre-change source/provenance, not assumed to use the same baseline after this production update. Final supported WASM build and artifact hashes accompany this gate; deployment recorded separately after completion.
