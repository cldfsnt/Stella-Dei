# Explicit paid rooted founder, existing live Wetlands physiology3

Separate copy `site-tmp/rooted-founder/src`, based on live Wetlands. No physics/schema/default changes: v10, physiology3, Origin revision5. No law4 or Wind composition. Existing ordinary actions remain untouched.

`stella_rooted_founder_preview(world:u32,point:u32)` and `stella_seed_rooted(world:u32,point:u32,token:u32)` return JSON. Native acceptance may call `rootedFounderForState(state,world,point,apply)` directly (same body). Keys: world_serial,cell,token,status,founder_id decimal string (empty on refusal), carbon_kg_m2 (actual created live C), nitrogen_kg_m2 (actual mineral debit), carbon_source_kg (absolute atmospheric C paid), carbon_rounding_kg (conservative excess), support_kg_c_m2,root_kg_c_m2,root_fraction,organization,soil_kg_m2,depth_m. Preview is read-only; eligible preview founder_id is prospective and must not be advertised as already created. Apply recomputes all conditions. Preview issues a one-use token bound to exact selected-cell/stats/atmosphere/soil/water/temperature/geometry conversion/config snapshot. Apply consumes the matching token before any attempt and rejects changed material state; duplicate apply refuses. New preview supersedes old. `stella_rooted_founder_cancel(token)` clears only matching plan. Successful save loads increment an ephemeral epoch so even identical loaded material invalidates a pending plan. No saved plan or nonce.

Statuses: eligible (preview), planted (apply), disabled (wrong world/law/absent state), invalid, stale (world or selected point mismatch), busy (Advance/escape/climate/native Details/geometry job), too_cold,too_hot,too_deep,no_soil,no_space,no_nutrients,no_carbon,unrepresentable. Refusal never commits staged state or changes RNG. UI should verify successful current-world/point receipt and exact new founder ID, not assume dominant cohort. Success uses existing Pin with actual new lineage and morphology; pause/camera/time stay unchanged. Closing HTML controls is frontend-owned.

Chosen founder: root fraction .5, organization .25, support_mass .25*actual seeded C. Support is a subset: full .02C yields .005support, .0025roots, .0025aboveground, .015fronds. Other traits retain ordinary founder defaults, including structure0; generation0,parent0,credit0. These are explicit initial genetics, not evolved adaptation or proof of uptake/survival. Existing seed semantics increments next_lineage, not offspring births.

Budget follows ordinary min(.02, available carbon, mineral nutrient/.1), reporting actual amount. A free cohort slot and total resulting biomass<=1 are required. Rooted action additionally requires valid exact law3 Origin, finite temperature strictly273.15..355K, depth0..50m, and authoritative soil in[0,1]kg water/m². At depth<.2m require existing soil>0; this is not a tuned survival threshold. No water, soil, nutrient, support carbon or reproduction credit grants. Seed C is charged to atmosphere with ordinary stoichiometry/O2 and fixed-carbon accounting. Represented C/N source debit is checked before commit, rounding source stock downward by at most one ULP if needed to avoid overcredit; report actual debit rather than claiming mathematical exactness. No new arbitrary full-budget minimum.

Implementation is a single new helper plus guarded main exports, not a physiology hook. Historical simulation/core files and save schema are unchanged byte-for-byte; successful save apply only invalidates the ephemeral confirmation epoch. Pure suite passes; first whitespace compile failure retained. Final native public action, exact delta/refusals, ordinary/off-path full state/RNG, actual paused terrain actions,24h/restart usefulness remain independent release gates.
