# Selected Sandbox patch: last completed interval

Session-only read-only observer. Bind Planet pointer, vegetation storage, world serial and one selected cell; no per-cell buffer, saved fields or scan. Actual scheduler order is animal grazing THEN intrinsic vegetation update THEN colonization/replacement and final clamp. The receipt records those represented cover deltas, not desired feeding, inferred causality, carbon mass or gross photosynthesis. `physiology` is net intrinsic growth/loss; `spread` includes actual cover addition from colonization/replacement. `clamp` remains separate. Endpoint net and explicit arithmetic/unaccounted residual retained. Values are patch cover fractions, not percent biomass.

One fresh receipt replaces the prior on every positive-dt completed scheduler interval. Partial/invalid/zero-dt interval has no receipt; no rolling-history claim. Query is pure and requires matching cell, world, mode, storage, exact endpoint time and endpoint cover. Paused time does not accrue; the last completed interval can remain visible with its stated duration. Selection, load and direct action invalidation are explicit. Successful save.apply reset is necessary: direct same-world load need not change world serial. No invalid-load mutation.

Pure controls plus fixed actual warm classic patch436 and enabled Tough26788,60ticks each, observer off/on complete save/RNG endpoint equality. Instrumented copy logs each actual selected phase before/after operand; offline Fraction reconstructs binary f32 operands and checks every phase, source debit and endpoint residual exactly. This is a diagnostic gate, not a new physical conservation model or performance benchmark. UI integration/purity and screenshots follow once v70 frozen deployment is complete.
