# Paused native basin confirmation candidate

`habitat_preview.zig` holds a private one-use pending plan. Four JSON/browser exports are added: `stella_habitat_prepare(world, cell, nursery)`, `stella_habitat_execute(token)`, `stella_habitat_status()`, and void `stella_habitat_cancel()`.

Prepare requires current Origin, explicit paused state, current world and selected cell. There is no implicit pause. It snapshots exact gameTime, owner, full footprint Microbes.Cell values (not just counts), ordered terrain plan and all outside dependencies. Execute consumes the token on any attempt, validates those dependencies, then writes only the planned terrain/water. Prepare never advances physics or edits biology. Successful execute sets a static transient feedback message, not a saved field. Token exhaustion refuses rather than wrapping. Load/world lifecycle resets cancel pending tickets. Play.update checks pending freshness, with no cell scan when none exists; explicit speed setting also cancels. Same-time observed unpause followed by re-pause refuses. Legacy public pond/nursery exports are retained for compatibility; safeguards apply to the new checked route, not universal denial of all old APIs.

Prepare/execute share an identical receipt, except manual=false/true. It includes ordered floor_ids/rim_ids, actual floor/rim counts, occupied floor/rim patch counts, center/other-floor/rim intended depths, and warning that raising/drying the rim affects living colonies. `water_added_kg` and `water_removed_kg` are external model water changes: Planet.getKmPerWaterMass documents native units as 10^9 kg, so conversion is ×1e9, not an area multiplication. The supplementary `_depth_sum_m` fields are summed depth equivalents across affected patches, not depth at one patch. Neither measure represents conserved/excavated terrain energy or a biological benefit.
