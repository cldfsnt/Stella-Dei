## Reproduction
Run `python3 web/tests/egl-early-flow-prepare.py ABS_OUT/src`, then Zig0.13 build with `--build-file web/tests/egl-propagule-visual-build.zig -Dsource=ABS_OUT/src/main.zig --prefix ABS_OUT/build` and suitable cache directories. Run binary with LIBGL_ALWAYS_SOFTWARE=1, QA_FLOW_SEED=42/1337/2027, STELLA_ORIGIN_WIDTH=390 (also320 for2027), and absolute STELLA_EGL_CAPTURE_PREFIX. No timing benchmark is claimed.
