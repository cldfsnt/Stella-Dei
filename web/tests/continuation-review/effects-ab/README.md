# Are arrival/death cues the bottleneck? Controlled native investigation

Research only; no production drawing was removed. Same binary, native llvmpipe, browser rendering policy at1366×768, full pump/update/render/gl.finish/swap measurements. OFF skips only actual propagule cue/legend drawing after real event ingestion/projection; simulation, receipt ingestion, pulse aging, colony glyphs, camera and pace remain unchanged.

A genuine30day QA world was advanced32.8 further simulated hours using the actual full scheduler until12 real receipts existed:9 arrivals and3 tracked losses. No organisms, histories, event counters, food or traits were injected. Real receipt/pulse snapshots were restored alongside the same saved world before each pace. Measured busy frames drew9–10.7 cues/frame, below the production12-pulse bound. This is not an unbounded icon explosion.

Thus there is **no consistent large rendering benefit** from hiding these cues in this proxy.
