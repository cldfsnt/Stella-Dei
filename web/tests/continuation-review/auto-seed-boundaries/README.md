## Accounting limits retained

The emitted measured biomass delta therefore sees only the new empty-cell slot, not both receipts. Do not infer missing seeds from that diagnostic or call it exact physical inventory. Native gas decreases and counter outputs are preserved verbatim. No tolerance was widened or production law changed.
