## Corrected conclusion and next decision

The24h small-founder failure does not establish that a dormant bank/new persistence physiology is required. Existing heritable toughness already lowers dry mortality with costs, and larger existing colonies can have much longer analytic time above the numerical establishment cutoff. Conversely, these archived worlds do not contain a highly tough near1 strategy; actual maxima yield modest intrinsic drying-rate differences.

Before new physiology, a prospective whole-phenotype experiment could compare existing paid colonies under the SAME declared wet/dry/rewet schedule, with starting mass and traits reported separately. That would test whole-phenotype availability, not isolate toughness causation. No such followup is selected or executed here; no favorable rerun replaces earlier failures.
