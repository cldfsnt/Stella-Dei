# v34 competition summary

UI-only change. Life snapshot now shows current living lineage count, largest cohort's biomass share, model slot saturation when all four cohort places are occupied, grazing capability, and paid support costs. It does not infer current feeding, predict a winner, label drying resistance as armor, or advance simulation. Invalid/non-Origin snapshots clear the section. Current simulation and save code are identical to v33.

Seven production Node regression suites pass, including new summary calculation, empty/invalid handling, immutable input, no invented grazer/support, four-slot saturation, and clearing when switching to Sandbox. A managed-browser fixture rendered the real shell with explicitly constructed snapshots in a374px-wide dialog. Text wrapped and the Close button worked; the longer first draft was shortened afterward and Node tests rerun. This is interface-fixture testing, NOT live browser gameplay or Android-device verification. Cloud WebGL gameplay remains subject to the previously recorded graphics initialization limitation.

The habitat-factorial experiments alongside this release are research evidence, not a changed evolutionary model. No rejected grazing candidate is included in production.
