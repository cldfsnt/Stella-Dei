## Consequence for a routing experiment

A naive longer random walk lowers rather than raises the overall probability of an empty habitable landing for these potential donors. It can reach one additional current niche, but **does not justify shipping long-distance routing as a solved spread bottleneck**, promising a fixed number of colonies, or searching successively farther until a favorable destination appears.

If parent approves a narrow hypothesis test, use a frozen rare chance (e.g.5%) to replace, not add to, an already earned exploratory propagation attempt with a4-edge unbiased path; compare normal routing from exactly the same saved world, retain all failed/harsh/occupied/source-return destinations and actual event-time donor availability. Existing .004 offspring biomass/proportional support and .01 earned-credit debit must remain funded, and no new offspring may be created on a failed landing. Four rather than eight steps is sufficient to test the sole newly reachable niche;8 has no extra distinct empty habitat in this snapshot. This is a proposed test, not implemented or approved production. With a5% mixture, the frozen geometric mean empty-habitat probability would be about3.12%, not better than the3.17% adjacent reference; only about0.060% of all attempts would target empty suitable endpoints more than onehop away under the4-step mixture. Actual event weights can differ substantially.

**Temporal/hazard requirement:** traversing several~90km cells cannot silently become instantaneous risk-free teleportation. Before a production design, specify transit duration against the actual game clock and how intermediate hostile exposure, settlement failure and paid carbon/N fate are represented. A pure static route-kernel A/B would only test opportunity, not validate transport biology. Do not call it feeding-dependent mobility: current mobility relocates feeding cohorts toward richer adjacent prey; this proposed passive propagule route is distinct. No inherited dispersal trait, save schema or arbitrary movement-energy subsidy is added here.

Parent/family caveat remains: existing feeding can preserve a parent while reducing connected descendant biomass; this graph does not prove predators caused any absent daughter, nor that distant dispersal would rescue them. Ancestry-resolved transaction evidence remains a separate question.
