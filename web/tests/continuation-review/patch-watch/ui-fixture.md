Actual shell and patch-watch controller, with explicitly mocked WASM data, tested through the supported browser UI. Dialog constrained to374px and HUD354px inside a wide viewport; this is not Android or actual browser-game verification.

Watch button visible at top of Life snapshot. Starting closes modal and reveals legible phone-width HUD; finite small intake displays in significant figures. Completion permits dismiss; repeat starts afresh. Opening More immediately cancels; after closing More, HUD retains stopped/cancelled observation and Dismiss. No clipped text or control overlap in inspected HUD screenshot. Initial fixture omitted an existing water export required to populate selected patch; failed honestly with start guidance. Adding the existing export to fixture corrected it; no gameplay changes were made for that fixture omission.

The simulated times/intake in this fixture are mocked, not evidence of real ecology. Native acceptance separately validates actual scheduler flux, save parity and pointer selection.
