Baseline latest tested protective-ui engine/frontend; no Site/live changes. Native owner review_changes, storage owner combined_storage. New isolated unified-ui only after contracts agreed. No new host/mode/experiment destination.

## One obvious path
- Main identity “Stella Dei”. Remove open Wetlands experimental overlay and all preview/back-main links from normal startup. One concise welcome: create a new evolving world or open an existing saved world. No automatic creation followed by a second reset, and no automatic save/load.
- New world defaults to tested integrated root3/wind1/calmer/protective15, paused, with founders still0. Replace climate/protection checkbox maze with one New world action. Explanation belongs in collapsed World details: finite soil, costly inherited wind/root/cold-heat strategies; additional simulation work may run slower; no promise of land establishment.
- Existing saved-world selection is explicit. A saved older world keeps its actual law and identity, not silently upgraded. Resume means load a selected saved world; Continue means return to the currently open world without a reload. Save/new warns about the actual slot and saves/verifies before replacement. Do not call a new factory if save/backup/identity guard fails.
- Normal Observe path remains Find life, growth-form visits, exact colony inspection, advance/watch and ecosystem counts. Start with simple aquatic life; rooted chosen founders are optional assistance, not prerequisite for evolution.
- Advanced Sandbox can stay in an advanced World section if supported natively; not a competing startup product. No preset collection or experiment-link carousel.

## Save plan (must settle before coding)
Discover old main /saves, standalone /wind-saves and current /wetlands-saves independently. Never implicitly merge, delete, migrate, or overwrite. Explicit list names source + version + available metadata. Read-only source copy, hash validation and durable current recovery checkpoint before a supported load; old source bytes stay intact. Existing main backups/localStorage fallbacks must not be consumed by new initialization. Read-only discovery must not flush dirty candidate memory into old databases. Unsupported/corrupt entries remain downloadable/preserved, not claimed loadable.
Native import should use existing atomic validated-load logic plus full currentworld/epoch guard and immutable current recovery backup. Merely copying bytes into canonical slot then calling load is unsafe because invalid import would overwrite saved bytes. Child must specify staging path and source persistence behavior; native owner must approve supportedschema routing. Default/new main writes stay in one proven slot; selecting an old world never changes source until explicit Save action and clear destination.
