# v22 · Frame nearby life

Explicit More → Fit nearby life action frames the nearby connected aquatic
colony cluster in Origin. It does not create, feed, move or evolve organisms.
Search is deliberately local to the current view, not a global jump to an
unrelated colony. No automatic recentering interrupts exploration.

Native saved-world comparisons across 320px and 390px portrait and 800px
landscape showed occupied patches visible before → after:
- Seed42: 6→8, 6→8, 8→8.
- Seed2027: 3→5, 4→5, 3→5.

These are actual native game screenshots, not Android browser performance proof.
The worlds are saved outcomes of earlier simulation runs; this is a camera test,
not new evidence of biological growth. Fast-forward and measured-rate reporting
from v21 remain unchanged. Blender asset and reserve-physiology work remains
experimental and is not included in this release.

All six native cases preserve the full saved-world/resource state after normalizing only camera fields. Repeated actions are idempotent, empty/no-world cases fail safely, and real Inspect taps hit every fitted occupied patch (8/8 or 5/5). See fit-life/REPORT.md and its evidence.
