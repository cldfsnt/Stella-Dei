# Isolated inherited motility precursor

Whole resident cohorts can relocate to adjacent suitable wet patches with more
real competing prey. No fractional clones, unrestricted teleport search or
occupied-slot replacement. Movement preserves lineage identity and intake
history, consumes oxygen and respires carbon; its bound nutrient returns at the
source. Ongoing photosynthesis/maintenance costs make mobility a tradeoff.
This is coarse patch migration, not a simulation of individual animal motion.

Three mechanism tests pass. Across32 matched deterministic replicates, genuine
inherited motile grazers yield21survivors vs0immobile after30darkdays seeking
adjacent real prey.21actual moves, no duplicate lineage. After explicit4day
sunlight recovery,21surviving lineages fund inherited gen2offspring. No organisms
are respawned; weak variants need not reproduce in darkness. Conservation,
adjacency, unsuitable destination, oxygen refusal, occupancy refusal and benign
photosynthetic cost pass. Prototype uses a deterministic useful mutation fixture,
not a guarantee that every newworld produces it.

Next candidate must use bounded neighbor lookups, oxygen-accounted world flux,
real time-stamped relocation events, exact old-save defaults and player-visible
prey encounter feedback. Ordinaryworld/render/save tests still pending. Production
v14 unchanged while this prototype is isolated.
