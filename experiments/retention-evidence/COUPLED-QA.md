# Paired100-day actual-engine moist-shore test

Experimental only; no main edits, deployment or migration of user saves. This is not proof of terrestrial vascular plants, drought-resilient forests, seedbanks or fire recovery.

## Honest setup
Deterministic Continents planet, actual fixed1440-second physical ticks. Existing Make Nursery action centered30114 places30111 on its dry outer rim (graph distance2), followed by one ordinary Seed. No assigned inherited traits, free descendants, hidden irrigation, repeated terrain actions or climatic tuning. The geometry changes local weather, so the previous unmodified30111 replay trace is not reused as a full-world prediction.

Both reserve-on and reserve-off arms restore exactly the same serialized experimental schema7 initial state; all initial body reserves are zero. The30-day and100-day initial files are themselves identical, SHA25657334a6bbb71fe4b8f3cebfdfc49ddcae9d7b7df40bffe7e0c27eb237630bb83. Reservoir/shore actions and one ancestor are user-like actions, not biological fixture assignment.

The reserve model retains its costs, finite paid uptake, existing inherited mutation, donor-funded propagules and tissue maintenance. Disabling reserve changes only its documented experimental physiology flag. As ecological trajectories diverge, climate and selection feedback are measured rather than assumed equal.

## Interpretation
Reserves increased shallow fixation and cohort count in this one paired world but did not increase total biomass or accelerate target colonization. The prior replay shows a conditional storage mechanism, while this coupled test shows that moist-shore progression works even with reserves disabled. Neither supports claiming a robust reserve advantage or warrants live schema7 migration by itself. One seed/counterfactual pair is not a general fitness ranking.
